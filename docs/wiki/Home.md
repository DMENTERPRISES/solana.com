## 🎯 Repository Overview

**Solana.com** is a monorepo containing multiple applications and shared packages for the Solana ecosystem website.

### Key Features
- ✅ Multiple Next.js applications
- ✅ Shared UI components and packages
- ✅ TypeScript for type safety
- ✅ TinaCMS for content management
- ✅ Internationalization (i18n) support
- ✅ Optimized build system with Turbo

### Technology Stack
| Category | Technologies |
|----------|---------------|
| **Package Manager** | pnpm |
| **Build System** | Turbo |
| **Framework** | Next.js 15 |
| **Language** | TypeScript, MDX |
| **Styling** | Tailwind CSS |
| **Content** | TinaCMS, MDX |
| **Code Quality** | ESLint, Prettier, Husky |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/DMENTERPRISES/solana.com.git
cd solana.com

# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
